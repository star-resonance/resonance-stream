## 개발자용 상세

0.6.3 is a patch release on top of 0.6.2. Its one user-facing change is the guild Discord relay; the rest is internal.

**Guild relay** (#376; API v1 from #367; the broker is `star-resonance/guild-relay-worker`)
- #366: `own_player()` reads the player's uid and guild ID from the compressed `0x8002` world-state record; the pipeline reports it on change.
- #377: core `GuildRelay`: only live GUILD lines with a sender and a send time; nothing but the enrollment question leaves the PC until the broker says the guild is enrolled; batches of 20 at most every 2 s, 500 queued at most; 403 means no longer enrolled; 413 halves the batch; 429 and 5xx back off from 2 s to 5 min. Each message carries its origin (live, history, replay).
- #379: the relay worker starts with the app, sends the requests and reports `guild-relay-state` (with a growing seq) to the ui.
- #380: Settings > 길드 릴레이: the switch (off by default), the broker URL and one Korean sentence per status.
- #381, #384: the default broker is `GUILD_RELAY_BROKER_URL`, read with `option_env!` at build time from the repository variable; a build without it has no default broker.
- #385: a Japanese name is sent as `name(Romaji)` when that fits in 32 characters, else the name alone.

**Internal**
- S8b-S8e (#329, #334, #336, #337, #339, #340, #341): owners for the app's process statics; typed ipc (44 commands, 13 events pinned by tests); the bridge calls plain functions on one async task; `flow::dispatch` and `run_translation_job` behind a `Sink`, shared by the app and the test harness.
- S7 (#346-#348): capture sanitiser and a sanitised corpus with its decoded snapshot.
- #351: `--devtools-port` for the main window and every popup.
- Release flow (#333, #360-#363): Candidate on `main`, Promote on `rc/<tag>`; the old release workflows are gone.
- Dependencies: base64 0.23, sha2 0.11, etherparse 0.21, zip 9, ruzstd 0.9.1, rustls 0.23.46, plus Dependabot's action and npm bumps.

**Known**
- #382: after the relay is switched on, the guild can take minutes to arrive (it comes only with the own-player world-state record).
- #383: the debug console in selection mode freezes capture and IPC (debug builds only).

**Not verified on Windows before this candidate**: the relay from a release build (the earlier end-to-end runs used debug builds and reached Discord); the reading after a Japanese name in Discord.
