- 즐겨찾기 탭 이름이 같아도 되고, 탭 위치를 바꿔도 메시지가 다른 탭으로 섞이지 않아요.
- 즐겨찾기와 직업 · 던전 이름 창을 Esc 키로 닫을 수 있어요.
- 창을 닫았다 열 때마다 조금씩 커지던 문제와, 설정을 연 채로 닫으면 커진 크기가 저장되던 문제를 고쳤어요.
- 팝업 창이 닫기 전 크기와 위치로 다시 열려요.
- 좁은 창에서 탭이 위쪽 버튼 밑으로 들어가던 문제를 고쳤어요.
- VPN 때문에 채팅이 잡히지 않을 때 어느 VPN이 원인인지 알려 줘요.
- 번역이 채팅 줄보다 먼저 도착해도 빠지지 않고 붙어요. 차단한 사람의 예전 채팅도 다시 열었을 때 돌아오지 않아요.
- 채팅은 번역이 어떻게 되든 도착하는 즉시 기록에 남아요.
- 설정 파일을 읽거나 쓰지 못했을 때 조용히 사라지지 않고 알려 줘요.
- 업데이트 설치가 실패하면 원래 프로그램을 되돌려 놓고, 번역 엔진 설치가 중간에 끊겨도 설치된 것으로 보지 않아요.
- 번역 엔진 파일이 정해진 것과 다르면 관리자 권한으로 실행하지 않아요.
- 사전이 새로 나왔어요. 시즌 3 던전 이름과 직업 계열 이름이 들어갔고, 설정에서 지금 쓰는 사전과 동기화 결과를 볼 수 있어요.

## 개발자용 상세

0.6.2 is the first stable release with the signed metadata path and the 2026-10 architecture work (S0-S8a). The previous stable is 0.6.1; the full commit list follows on the release page.

**Signed metadata (D-28, D-29)**
- The model and dictionary metadata are read from the signed `metadata` branch (`metadata-v1`, `metadata-v2` published; dictionary 1.0.8 is `metadata-v3`, whose tag Kade pushes, #266). The app refuses what does not verify; the first-run wizard says why it stopped (M1-M3).
- N-1/N-2/N-6: the dictionary sync button shows how it ended; `sync_dictionary` has no `version` argument; settings show the dictionary in use (version, signed revision, same / modified).
- N-5: `download_model` takes no arguments and verifies the metadata at every download.
- Only copies on 0.6.2 or later read the signed metadata; 0.6.x copies keep reading the gist, which is left as it is.

**Do not lose the app or data (S1, S2)**
- Failed update install restores the running exe (`install_swap`); AI-server extraction goes to `.part` first; panic hook writes `panic.log`; chat is archived on arrival; unreadable / unwritable `config.json` is reported; `config.json` carries `config_version`; one `AppConfig` for backend and ui; channel limits decided in one place (WORLD 500, others 1000, D-1).

**Trust boundary (S3)**
- The elevated AI server starts only when its files match the pinned SHA-256 table; small remote calls have timeouts and size limits; the webview holds no shell / opener permission and `open_browser` opens only https; a Content-Security-Policy is pinned (S3c-2).

**Capture, translation, ui (S4-S6)**
- Duplicate window handled in the pipeline (D-27); sniffer restart waits for the old thread; one owner for the translator; raw-socket setup failures show as the sniffer's error; the firewall check no longer freezes the window; routes through a VPN adapter are not trusted and the watchdog names the VPN.
- `[P0]` typed in chat is shielded (W-11); a leaked `<start_of_turn>model` header is removed whole (W-12); the nickname lock is held only to pick names (P-6).
- Chat list drops older pages at the bottom (P-1), furigana requests are batched (P-3), one scroll effect (P-2), `ChatRow` split (R-5).
- K26: favorites tabs are identified by id (config migration on load, no backup file).

**Test and release machinery** (not user visible): the test bridge and runbook pipelines (`python -m runbook.run`), stand-in llama-server, weekly mutation tests and `cargo audit`, golden text tests, smoke test only from a release tag.
